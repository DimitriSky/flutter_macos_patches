## 0.1.0

- Give the Flutter text input view the standard macOS commands `paste:`, `copy:`, `cut:` and
  `selectAll:` working on the Flutter editing model, and enable or disable their menu items by it.
  Edit menu items and tools that inject a Cmd+V (dictation, text expanders) now reach Flutter fields.
- `MacosEditActions.status()` and `setEnabled()` for diagnostics and A/B checks.
